📖 Cómo usar

Para ejecutar un cheat (solo si lo necesitas para investigar):

1. Copia el archivo .DLL a una carpeta temporal

2. Abre PowerShell como Admin

3. Ejecuta: [Reflection.Assembly]::Load([IO.File]::ReadAllBytes("C:\ruta\archivo.dll"))

Interpretando resultados:

🔴 Rojo: Evidencia fuerte de cheating — revisar hallazgos

🟡 Amarillo: Señales sospechosas — preguntar al jugador

🟢 Verde: Sin coincidencias con firmas conocidas
