📖 Cómo se usa

1. Pulsa ➕ Generar código, elige la plataforma (Java, Bedrock o Móvil) y, si quieres, una nota (por ejemplo el nick).

2. Pásale al jugador el SSHelper.exe (Java/Bedrock en PC) o la app SSHelper (móvil) y el código. La 1.ª letra del código indica la plataforma: SS-J… Java, SS-B… Bedrock, SS-M… móvil. Un código de móvil no funciona en el exe de PC y viceversa.

3. El jugador abre el programa (mejor como administrador), escribe el código y espera el escaneo.

4. El resultado aparece aquí solo (se actualiza cada 30 s). El código pasa de ⏳ Pendiente a un veredicto.

Veredictos: 🔴 evidencia fuerte · 🟡 señales sospechosas, pregunta al jugador · 🟢 sin coincidencias con las firmas conocidas. Los hallazgos con probable falso positivo no cuentan para el veredicto, pero revísalos.

Si el envío falla el programa guarda un .json local: usa 📥 Importar para verlo aquí.

Firmas propias: sube config/signatures.json al repo con listas strong, weak, ambiguous, tools, evasion; el exe las lee sin recompilar.
