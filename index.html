Guía rápida del moderador

Qué significa cada hallazgo y qué hacer con él
🔴 CHEATING — Evidencia fuerte
Coincidencia directa: hash de archivo conocido, nombre de cliente cargado en memoria, log del sistema borrado recientemente. Revisa el detalle de cada hallazgo (ruta, fecha, contexto) antes de sancionar — úsalos como evidencia junto con lo que viste en el juego.
🟡 SOSPECHOSO — Revisar
Señales que ameritan preguntar más: software de macros, DLLs no estándar, USB desconectado antes del SS, argumento Java raro. Muchas tienen explicación legítima — pregúntale al jugador antes de concluir algo.
🟢 LIMPIO — Sin hallazgos
No se encontraron coincidencias con las firmas actuales. No es garantía absoluta (clientes nuevos u ofuscados pueden no detectarse), pero no hay nada que reportar.
⚠️ FALSO POSITIVO PROBABLE — Descartado
El escáner detectó una palabra clave, pero el contexto indica que proviene de un resource pack, cosmético, o mod legítimo — no de un cliente de hacks. Por ejemplo: "ravenb" en la ruta cosmetics/wings/ravenblackwings.webp, o "huzuni" como nombre de un ítem cosmético en una skin pack. No sanciones por estos hallazgos.
📁 Archivos / Prefetch
Carpetas, JARs o programas con nombres de hacks encontrados en el disco o en el historial de ejecución de Windows. El Prefetch registra automáticamente cada programa que se ejecutó, aunque ya no esté instalado.
🧠 Memoria / DLLs
Cadenas encontradas en la RAM activa de Minecraft o módulos cargados dentro del proceso. Es la señal más directa de un cliente inyectado — pero siempre verifica el contexto antes de sacar conclusiones.
🖱️ USB — Dispositivos y macros
Historial completo de dispositivos conectados y desconectados. Presta especial atención a desconexiones en la última hora — puede indicar que retiraron un dispositivo con hacks antes del escaneo. El software gaming (Razer, Logitech G HUB) es contexto, no evidencia.
🕵️ Evasión
Señales de que algo se borró u ocultó: logs del sistema eliminados, servicios clave detenidos, archivos enviados a la papelera recientemente. Combinado con otros hallazgos, es evidencia muy relevante.
